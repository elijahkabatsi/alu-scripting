ALU Scripting

This repository contains completed scripting projects. It includes tasks focused on Bash scripting, Python scripting, and API interaction.

Folder Structure

api_advanced/ — Python scripts for interacting with REST APIs (subreddit data, recursion, keyword counting, etc.).

Usage

Clone the repository:

git clone https://github.com/elijahkabatsi/alu-scripting.git
cd alu-scripting


Run Python scripts:

python3 filename.py
